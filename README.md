⚽ Turf Online Booking System

A clean, modern, and fully functional Turf Booking Web Application built using HTML, CSS, and JavaScript.
Users can browse turfs, choose a time slot, book directly, and manage their bookings using localStorage.

🚀 Features
🏟 Turf Listing

Displays multiple turfs with:

Turf image

Location

Price per hour

“Book” button

🗓 Online Booking Form

Users can submit:

Turf name (auto-filled when clicking Book)

Date

Time slot

Customer name

Phone number

Additional notes

💾 LocalStorage Booking Management

✔ Saves all bookings in browser storage
✔ Displays list of all bookings
✔ Allows deletion (Cancel Booking)

📱 Responsive UI

Grid layout for turfs

Sidebar booking form

Works on desktop, tablet, and mobile

🎨 Modern Design

Gradient header

Card-based design

Hover animations

Smooth scrolling

🖥️ Technologies Used
Technology	Purpose
HTML5	Page structure
CSS3	Styling, layout, responsiveness
JavaScript (ES6)	Booking logic, UI update, localStorage
LocalStorage API	Persisting bookings
